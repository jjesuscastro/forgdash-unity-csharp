# Muse Dash Unity Remake

A fast-paced, rhythmic action game built in Unity, inspired by the mechanics and aesthetic of Muse Dash. This project replicates the iconic two-button combat system where players must strike enemies and dodge obstacles in sync with the music.

---

## 🕹 Controls

The game uses the classic Muse Dash input scheme, allowing for high-speed rhythmic play:

* **Top Lane (Air Attacks):** Press **F** or **D** (or Up Arrow)
* **Bottom Lane (Ground Attacks):** Press **J** or **K** (or Down Arrow)
* **Long Notes (Hold):** Hold the corresponding key for the duration of the note.
* **Dual Hits:** Press both Top and Bottom keys simultaneously for purple enemies.

---

## ✨ Features

### 1. Two-Lane Combat
Experience the seamless blend of side-scrolling action and rhythm. Enemies approach from two heights, requiring quick reflexes and precise timing.
